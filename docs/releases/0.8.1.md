## Package names

All packages now use the personal `@kiaa` npm scope:

- `@kiaa/dotimation-core`: framework-independent runtime.
- `@kiaa/dotimation-react`: React 19 adapter, replacing `dotimation`.
- `@kiaa/dotimation-svelte`: Svelte 5 adapter.

## Migration

Replace the `dotimation` dependency with `@kiaa/dotimation-react` and update imports. The React component API remains unchanged. Both adapters automatically install `@kiaa/dotimation-core`. The former `@dotimation/core` and `@dotimation/svelte` names were never published.

## Maintenance

Updated workspace aliases, package consumers, documentation, and distribution checks for the new names. Releases keep all three packages synchronized and publish tested tarballs through npm Trusted Publishing after initial package setup.
